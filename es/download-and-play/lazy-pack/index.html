    Guía de descarga del pack de mods y paquete perezoso para jugadores¶

    GTE (GregTech Easy) ofrece tres formatos de entrega listos para usar para jugadores y administradores de servidores con diferentes niveles técnicos:

    1. Paquete perezoso completo sin compilar para jugadores (GTE-LazyPack-*.zip) : Incluye todos los mods precompilados, configuraciones, scripts de modificación y la estructura completa del directorio .minecraft, ¡doble clic o arrástralo al launcher y juega!
    2. Paquete estándar CurseForge (GTE-CurseForge-*.zip) : Formato estándar de CurseForge, se puede importar directamente con un clic en PCL2 / HMCL / CurseForge App / Prism Launcher.
    3. Paquete de servidor (GTE-Server-*.zip) : Incluye configuración de servidor limpia, mods y scripts de inicio, para jugar en línea en servidores.

    🚀 Paquete perezoso para jugadores (recomendado)¶

    Características y ventajas¶

    • 0 dependencias de compilación : No necesitas instalar el entorno de compilación JDK, IntelliJ IDEA ni Git.
    • Empaquetado completo : Los últimos JARs publicados de gtecore, gtm-reborn, gt-- y los mods de extensión previos ya están incluidos en el directorio mods/.
    • Arrastra y juega : Compatible con la importación de un clic arrastrando la ventana en PCL2 / HMCL.

    Pasos de importación e inicio¶

    1. Abre PCL2 (Plain Craft Launcher 2) o HMCL (Hello Minecraft! Launcher).
    2. Arrastra el GTE-LazyPack-<versión>.zip descargado directamente con el botón izquierdo del ratón a la ventana principal del launcher.
    3. El launcher lo reconocerá automáticamente y lo descomprimirá en la lista de versiones del juego.
    4. Ve a la configuración de versión de esa versión y especifica el runtime de Java como Java 21.
    5. Asigna 8GB ~ 12GB de memoria y ¡haz clic para iniciar el juego!
    1. Descomprime el archivo comprimido en cualquier ruta sin caracteres chinos ni espacios (por ejemplo, D:\Games\GTE\).
    2. Después de descomprimir, obtendrás un directorio .minecraft que contiene mods/, config/, kubejs/.
    3. Añade la versión del juego en el launcher y selecciona la carpeta .minecraft descomprimida como directorio raíz del juego.
    4. Asegúrate de seleccionar el núcleo Java 21 e inicia.

    ⚠️ Requisitos del entorno de ejecución Java 21 (extremadamente importante)¶

    [!CAUTION] ¡Este pack de mods requiere obligatoriamente Java 21 (JDK 21) como entorno de ejecución! No uses Java 17 ni Java 8, ¡de lo contrario el juego se bloqueará directamente o se negará a iniciar!

    ¿Por qué es obligatorio Java 21?¶

    • Los mods principales de GTE (gtecore, gtm-reborn, gt--) utilizan completamente características modernas del lenguaje Java 21 (como Record Patterns, Virtual Threads, Switch mejorado).
    • Los scripts de compilación de Gradle configuran globalmente JavaLanguageVersion.of(21) para forzar la verificación de la cadena de herramientas.

    Direcciones de descarga recomendadas para JDK 21¶

    Distribución Enlace de descarga Razón de recomendación
    Azul Zulu 21 (LTS) Haz clic para ir al sitio web de Azul Rendimiento excelente, optimización excelente para el multihilo a gran escala de Minecraft
    Eclipse Temurin 21 (LTS) Haz clic para ir al sitio web de Adoptium Recomendación oficial, alta compatibilidad y estabilidad
    Microsoft OpenJDK 21 Haz clic para ir al sitio web de Microsoft Buena adaptación nativa en plataformas Windows

    Configurar Java 21 en el launcher¶

    graph LR
    A[Abrir el launcher] --> B[Entrar en la configuración de versión de GTE]
    B --> C[Ruta de Java / Runtime]
    C --> D[Seleccionar el javaw.exe del JDK 21 instalado]
    D --> E[Asignar 8192MB ~ 12288MB de memoria]
    E --> F[Guardar e iniciar el juego]

    /ftbquests reload Recargar en caliente los archivos de configuración de FTB Quests Todos
    /kubejs reload server_scripts Recargar en caliente los scripts de modificación del servidor y las recetas Permiso de OP
    /kubejs reload client_scripts Recargar en caliente los scripts de modificación del cliente y la lógica de visualización Sin permisos
