# 超弦与阴阳高阶电路及材料系统

GTECore 拓展了横跨 ZPM 到 MAX 全周期的两大高阶电路分支 —— **超弦电路体系** 与 **阴阳太极电路体系**，并配合以矿石综合处理中心实现自动化材料大循环。

---

## 🌌 超弦电路体系 (Super String Circuitry)

超弦电路从高维震荡弦中获取超光速算力，主要覆盖 **ZPM ➜ UEV** 电压梯度：

```mermaid
graph LR
    A[超弦基板 / 印刷板] --> B[超弦处理器 ZPM]
    B --> C[超弦处理器集群 UV]
    C --> D[超弦处理器超级计算机 UHV]
    D --> E[超弦处理器主机 UEV]
```

### 超弦材料与弦系物质
- **起源之弦 (`item.gtecore.original_string`)**：高维宇宙震荡本源。
- **α弦 / β弦 / γ弦 (`alpha_string`, `beta_string`, `gamma_string`)**：不同能级与偏振态的超弦聚合物。
- **超弦混合机 (`super_string_mixer`)**、**创世之弦 (`string_of_creation`)** 与 **超弦震荡阵列 (`super_string_oscillator_array`)**：用于超弦物质的分裂、调谐与高阶固化。

## ☯️ 阴阳太极电路体系 (Yin-Yang Circuitry)

阴阳电路体系遵循 **“阴生阳，阳生阴，生生不息”** 的循环生克哲学，覆盖 **UV ➜ UIV** 乃至更高极限：

```mermaid
graph LR
    A[阴阳单晶硅 / 晶圆] --> B[阴阳处理器 UV]
    B --> C[阴阳处理器集群 UHV]
    C --> D[阴阳处理器超级计算机 UEV]
    D --> E[阴阳处理器主机 UIV]
```

### 八卦与五行专属符篆
- **五行元素**：金元素 (`jinyuansu`)、木元素 (`muyuansu`)、水元素 (`shuiyuansu`)、火元素 (`huo`)、土元素 (`tuyuansu`)。
- **五行符篆**：金之符篆、木之符篆、水之符篆、火之符篆、土之符篆。
- **八卦象与芯片**：乾、坤、震、巽、坎、离、艮、兑八大卦象符石与核心芯片。
- **三清之粒 (`god_nugget`)**：凝聚天地玄黄之气的顶级合成媒介。

## 🌳 虚数基础材料与首棵虚数之树

虚数基础材料、控制器、单晶和晶圆配方均在 **UEV 电压**下制造或运行。先完成阴阳路线、UEV 部件和[三级净水体系](water-purification-system.md)，再用装配线、赤阳道核和坤艮星枢制造结构件，最后组装首棵虚数之树。

| 结构件 | 制造设备 | 每批产量 |
| :--- | :--- | ---: |
| 虚数外壳 | 装配线 | 32 |
| 虚数枝桠外壳 | 装配线 | 32 |
| 虚数约束外壳 | 装配线 | 16 |
| 虚数能量导管 | 装配线 | 16 |
| 虚数核心外壳 | 坤艮星枢 | 4 |
| 虚数玻璃 | 赤阳道核 | 32 |
| 虚数线圈方块 | 坤艮星枢 | 8 |
| 虚数叶矩阵 | 装配线 | 64 |

首树可由既有的**阴阳 UIV 电路**启动：核心外壳使用阴阳处理器主机，控制器使用 UIV 电路，并需先扫描研究虚数核心外壳。UIV 是所需电路等级，制造配方及研究仍使用 UEV 电压；无需先造出虚数电路才能造树。

**虚数叶矩阵是固定结构方块，虚数生长介质是日常生产耗材。** 生长介质在树外由赤阳道核制造，每批消耗三级电子级净化水 4000 mB，产出 32 个。叶矩阵则在装配线中由虚数玻璃 4、枝桠外壳 4、生长介质 8、巽象、震象各 4，配合电子级净化水 4000 mB 和 Naquadria 1000 mB，批量产出 64 个，用于搭建树冠。

成型后，在虚数之树内持续生产：

- **单晶**：硅粉 64 + 生长介质 4 + 电子级净化水 4000 mB + Naquadria 1000 mB → 虚数单晶 4 个，UEV、30 秒。
- **普通晶圆**：虚数单晶 1 + 润滑油 1000 mB + 电子级净化水 1000 mB → 虚数晶圆 16 片，UEV、15 秒。

单晶生产消耗生长介质，不拆耗树冠叶矩阵。结构材料、造树入口和单晶/普通晶圆路线已接通，接下来用专用光刻中心加工芯片。

### 虚数浸没光刻中心

**虚数浸没光刻中心**承接虚数之树产出的普通虚数晶圆，只运行专用的虚数浸没光刻配方。控制器在装配线制造：使用既有虚数结构件、UEV 部件、4 个 UIV 电路（可用阴阳处理器主机）和 4 片普通虚数晶圆；先扫描研究普通虚数晶圆。研究和制造均为 **UEV**，无需本机产出的 CPU 晶圆或芯片即可造出第一台。

以下五道工序均使用 **UEV 电压**。表中水量为每批直接消耗的**第三级电子级净化水**；曝光与刻模所需的**阴阳透镜不消耗，可重复使用**。

| 分支 / 工序 | 每批物品输入 | 电子级净化水 | 其他流体 | 每批输出 | 基础时间 |
| :--- | :--- | ---: | :--- | :--- | ---: |
| 电路：浸没曝光 | 普通虚数晶圆 1 + 阴阳透镜（不消耗） | 2000 mB | 过氧化氢 250 mB | 虚数 CPU 晶圆 1 | 30 秒 |
| 电路：晶圆切割 | 虚数 CPU 晶圆 1 | 1000 mB | 润滑油 250 mB | 虚数电路芯片 16 | 10 秒 |
| CPU：粗制切割 | 普通虚数晶圆 1 | 1000 mB | 润滑油 250 mB | 粗制虚数晶片 4 | 15 秒 |
| CPU：精密刻模 | 粗制虚数晶片 1 + 阴阳透镜（不消耗） | 500 mB | 氢氟酸 100 mB | 刻模虚数芯片 1 | 20 秒 |
| CPU：互连封装 | 刻模虚数芯片 1 + 铕细导线 4 | 500 mB | 焊锡合金 144 mB | 虚数 CPU 芯片 1 | 20 秒 |

两条分支分别为**普通晶圆 → CPU 晶圆 → 电路芯片**与**普通晶圆 → 粗制芯片 → 刻模芯片 → CPU 芯片**。把这些芯片送入封装厂，继续完成基板、印刷板与 SoC 的生产。

### 虚数基板封装厂

**虚数基板封装厂（Imaginary Circuit Fabricator）**是宽 × 高 × 深 **13 × 9 × 13** 的专用多方块设备。先扫描研究虚数 CPU 芯片，再在装配线制造控制器：使用既有虚数结构件、UEV 机械臂/活塞/泵各 4、前代 UIV 电路 4（可用阴阳处理器主机）、虚数 CPU 芯片 4 和虚数电路芯片 8，并消耗焊锡合金 5760 mB、聚苯并咪唑 1152 mB、电子级净化水 4000 mB。研究与制造均为 **UEV**；控制器不需要本机生产的基板、印刷板或 SoC，启动链不会自锁。

以下三道专用工序均为 **UEV**，水量为每批直接消耗的第三级电子级净化水：

| 工序 | 每批物品输入 | 电子级净化水 | 其他流体 | 每批输出 | 基础时间 |
| :--- | :--- | ---: | :--- | :--- | ---: |
| 基板层压 | 强化环氧树脂板 4 + 虚数生长介质 2 + 铕箔 16 | 2000 mB | 聚苯并咪唑 576 mB | 虚数之树电路基板 4 | 30 秒 |
| 印刷蚀刻 | 虚数之树电路基板 1 + 铕箔 8 + 金箔 8 | 1000 mB | 氯化铁 250 mB | 虚数之树印刷电路基板 1 | 20 秒 |
| SoC 封装 | 虚数 CPU 芯片 2 + 虚数电路芯片 4 + 虚数之树印刷电路基板 1 + 铕细导线 8 | 2000 mB | 焊锡合金 288 mB | 虚数之树 SoC 2 | 30 秒 |

### 返回虚数之树制造四档电路

四种成品仍在**虚数之树**中制造，**配方电压全部为 UEV**；UHV / UEV / UIV / UXV 是成品电路标签等级。UHV 处理器使用**三钛细导线 16**。下表水量不含前置材料的累计耗水：

| 成品电路等级 | 每批产量 | 基础时间 | 直接电子级净化水 |
| :--- | ---: | ---: | ---: |
| UHV 虚数处理器 | 4 | 20 秒 | 1000 mB |
| UEV 虚数处理器集群 | 2 | 30 秒 | 2000 mB |
| UIV 虚数超级计算机 | 1 | 45 秒 | 0 mB |
| UXV 虚数主机 | 1 | 60 秒 | 0 mB |

UIV 与 UXV 通过前置电路间接消耗净化水。至此，基板、印刷板、SoC 与四档成品电路的配方链已接通。

```mermaid
graph LR
    A[阴阳路线 + UEV 部件 + 三级净水] --> B[虚数之树：单晶与晶圆]
    B --> C[虚数浸没光刻中心：芯片]
    C --> D[虚数基板封装厂：基板、印刷板、SoC]
    D --> E[虚数之树：四档成品电路]
```

## 💎 矿石综合处理中心配方模式

**矿石综合处理中心 (`ore_process_center`)** 预设了 7 大标准化电路模式，可通过在机器内设置编程电路编号切换：

| 电路编号 | 工艺路线 | 适用矿物类型与产物特色 | 产出倍率 |
| :---: | :--- | :--- | :---: |
| **电路 1** | 粉碎 ➜ 粉碎 ➜ 洗矿 | 基础金属矿石（铁、铜、锡等）快速量产 | 5 倍主产物 + 副产物 |
| **电路 2** | 粉碎 ➜ 粉碎 ➜ 离心 | 伴生高价值稀有轻金属矿石 | 5 倍主产物 + 离心精纯副产物 |
| **电路 3** | 粉碎 ➜ 洗矿 ➜ 热离 ➜ 粉碎 | 高温耐火矿石、贵金属矿（铂系、金银等） | 5~6 倍 + 纯净金属粉 |
| **电路 4** | 粉碎 ➜ 热离 ➜ 粉碎 | 硫化物与重度复杂嵌布矿 | 5 倍 + 特殊热离副产物 |
| **电路 5** | 粉碎 ➜ 洗矿 ➜ 粉碎 ➜ 洗矿 | 稀土矿石与多阶段可溶性盐矿 | 6 倍 + 双重洗矿副产物 |
| **电路 6** | 粉碎 ➜ 洗矿 ➜ 粉碎 ➜ 离心 | 放射性重矿（铀、钍、钚系）与稀土 | 6 倍 + 精细离心重金属 |
| **电路 8** | 粉碎 ➜ 洗矿 ➜ 粉碎 ➜ 电磁选矿 | 强磁性与顺磁性矿物（磁铁矿、铬、钛等） | 6~8 倍 + 电磁纯净粉 |
